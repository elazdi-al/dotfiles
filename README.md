# dotfiles

- `nvim/`: Neovim config for Neovim 0.12, using the built-in `vim.pack` plugin manager. Symlink it to `~/.config/nvim`.
- `nix/`: nix-darwin and home-manager flake from 2025. It is not applied on the current machine and is kept for reference.

```sh
git clone https://github.com/elazdi-al/dotfiles ~/Code/dotfiles
ln -s ~/Code/dotfiles/nvim ~/.config/nvim
```
